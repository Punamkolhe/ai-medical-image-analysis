# 🩺 AI Medical Image Analyzer 

This project is based on an open-source repository.  
I have modified and improved it for learning and development purposes.

## 🚀 Features
- Upload medical images (X-ray, MRI, CT, etc.)
- AI-powered analysis using Google Gemini API
- Structured medical report generation
- Simple and clean Streamlit UI
- Download analysis report as text file

## 🛠 Tech Stack
- Python
- Streamlit
- Google Gemini API
- PIL (Python Imaging Library)

## 📌 My Contributions
- Improved UI using Streamlit layout
- Modularized code into separate files (`utils`, `models`)
- Integrated Gemini API for image analysis
- Added download report feature
- Improved prompt engineering for better output
